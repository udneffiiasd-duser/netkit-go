# netkit-go

Небольшой набор утилит для диагностики и связи узлов в локальной сети.
Всё написано на Go, собирается в один статический бинарник.

## Что внутри

- **runner** — сервер: слушает порт, принимает подключения узлов и раздаёт задания.
- **linker** — узел: подключается к серверу, держит соединение и выполняет задачи.

## Сборка

```bash
go build -o runner ./cmd/runner
go build -o linker ./cmd/linker
```

## Запуск

Сервер:

```bash
./runner -p 1337 -token "ключ"
```

Узел (через start.sh):

```bash
HOST=1.2.3.4 PORT=1337 ./start.sh
```

## Порядок работы

1. Сервер поднимается на порту.
2. Узел подключается и регистрируется.
3. Сервер выдаёт задание нужному числу свободных узлов (один узел — один слот).
4. Задание можно остановить, тогда слот освобождается.
